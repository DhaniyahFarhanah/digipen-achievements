Drop your SVGs in this folder. Any file you don't add falls back to the built-in icon.

FORMAT
- Square canvas (120 x 120 recommended; any square works).
- Icons: draw the whole tile edge to edge (background, corners, art). Leave a little
  padding if you want a gap around it.
- No embedded fonts/text (convert text to outlines) and no linked images.
- Locked versions are made automatically (greyscale), so draw each icon once.

FRAME (featured achievement)
- frame.svg        drawn BEHIND the icon. On a 120 x 120 canvas the icon sits at
                   x 21-99, y 21-99, so keep that square clear.
- frame-front.svg  optional, drawn ON TOP of the icon (claws, a head poking in, etc).
                   Transparent everywhere else.
